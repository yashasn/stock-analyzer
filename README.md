# stock-analyzer
Select a stock ticker and explore its historical data 

- User can select a particular ticker to find out the variation in its stock prices over a defined time period and analyze other aspects of it.
- Once the ticker is selected, the application presents the user with a wide variety of data related to the stocks of that company.
- The user can first visualize the changes in the Adjusted Close rates of the stock over the defined time period along with the Adjusted Opening, Volume, High and Low values.
- The application also takes into consideration if the company split or divided its stocks between the selected time period.
- Since not much can be inferred from only this data, the user is presented with the candle stick diagram representing open-high-low-close values over the time defined.
- Next, the stocks of the company are correlated to stock prices of S&P 500 Companies to realize its dependency or relationship with it using a heatmap.
